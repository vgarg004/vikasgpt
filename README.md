# vikasgpt
AI project to create a chatbot like chatgpt

# how to run the app

##1 clone github repo

```bash
git clone https://github.com/vgarg004/vikasgpt.git

##2 navigate to directory
cd vikasgpt

##3 create and activate venv

python3 -m venv vikasgpt
source vikasgpt/bin/activate

##4 install dependencies

pip install -r requirements.txt
